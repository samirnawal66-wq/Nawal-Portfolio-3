مشروع Portfolio الشخصي — نوال سمير

الملفات:
- index.html: محتوى الموقع وأقسامه.
- style.css: الألوان والتصميم والتجاوب مع الموبايل.

التشغيل:
1. ضعي الملفين في مجلد واحد.
2. افتحي index.html باستخدام متصفح أو محرر HTML يدعم المعاينة.
3. لتعديل الألوان، افتحي style.css وعدّلي القيم الموجودة في :root.
4. لتعديل النصوص، افتحي index.html وابحثي عن النص المطلوب تغييره.

قبل التسليم:
- استبدلي example@example.com ببريدك الحقيقي أو احذفي زر البريد.
- استبدلي رابط GitHub العام برابط حسابك بعد إنشائه.
- أضيفي مشروعاتك الحقيقية، وعدّلي المهارات لتطابق مستواك.
- ارفعي index.html وstyle.css إلى مستودع GitHub واحد.

ملاحظة: دائرة NS مكان مؤقت للصورة الشخصية. يمكن استبدالها بصورة عند تجهيز ملف الصورة وتحديث HTML وCSS.
